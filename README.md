# claude-code-tuts

claude : is used to start claude code
claude -r : is used to show previos chat
/resume: use to change session

1. one session = task
2. name your session immediately
    use /rename to rename a session. ex. /rename intro session
3. commit frequently wihtin a session.
4. export a session before a big refactor
5. /btw : used to ask any ques between the chat and that ques will not be the part of your conversation
6. /logout: to logout


Models:
1. Opus: most powerful but most expensive.used for complex programming task.
2. Sonnet: the default for most users. the best balance of speed, quality, token cost. good for everyday coding task.
3. Haeku: fastest and cheapest, use for simple and repeatative tasks, where you dont need deeply reasoning.
